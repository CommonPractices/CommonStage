CommonStage is the shared web presentation layer — the standard, templates, styling, config
schema, and generator behind every Org and product page. **This very site is built with it.**

It is at the **design stage**: the shape is settled and the first pages exist as hand-built proofs,
but the reusable generator has not been extracted yet. Shown here honestly as work in progress —
never dressed up as finished.
